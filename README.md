# Inplace Sorting Homework

## Описание

Решение задания по сортировкам.

Реализованы два алгоритма:

1. `insertion_sort` — сортировка вставками, сложность O(N^2)
2. `heap_sort` — пирамидальная сортировка, сложность O(N log N)

## Файлы

- `01.InplaceSorting/sorting.h` — реализации алгоритмов сортировки
- `01.InplaceSorting/sort_demo.cpp` — демонстрация работы
- `01.InplaceSorting/sort_test.cpp` — тесты
- `01.InplaceSorting/Makefile` — сборка проекта

## Запуск

```bash
cd 01.InplaceSorting
make
./sort_demo
./sort_test
